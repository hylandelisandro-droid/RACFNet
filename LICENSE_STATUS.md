# Publication and license status

## QSFNet boundary

The official QSFNet repository was inspected on 2026-10-17. Its repository
view and source tree did not expose a `LICENSE`, `COPYING` or equivalent
software-license file. Citation and public visibility alone do not authorize
redistribution.

Accordingly, this repository excludes copied QSFNet source. Users obtain
QSFNet from its official repository, and the included installer applies a
minimal RACFNet-original overlay to the user's own local copy.

## RACFNet-original materials

The current Private repository has no blanket open-source license. Before it
is changed to Public, the RACFNet copyright holder must choose and approve a
license for the original modules, patch, experiment drivers, configurations,
evaluation scripts, documentation, result tables and derived figures.

## Release decision

- Private technical review: **READY**.
- Public release: **HOLD** until the owner selects the license and explicitly
  authorizes changing repository visibility.
- QSFNet source redistribution: **NOT INCLUDED**.
